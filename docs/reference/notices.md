# Licenses and notices

The collection's own material uses its [MIT license](/notices/collection-LICENSE.txt), except where an imported asset or its notices specify another license. Cataloguing an upstream skill does not relicense or vendor it. Read the source entry's legal records before redistribution.

## Archify diagrams

The interactive diagrams contain generated Archify viewer code and embedded fonts. The external package remains pinned through the catalog; the website distributes rendered outputs, not a local installation of the skill source. These outputs retain the following software and font notices:

- <a href="../notices/archify/LICENSE-MIT" download>Historical MIT license</a>
- <a href="../notices/archify/NOTICE" download>NOTICE</a>
- <a href="../notices/archify/THIRD_PARTY_NOTICES.md" download>Third-party notices</a>
- [JetBrains Mono font OFL](/notices/archify/assets/JetBrainsMono-OFL.txt)

Do not remove the notices or assume that a historical MIT file overrides the package's current Apache-2.0 and mixed third-party records.

## Site dependencies

The site uses VitePress and Vue with their resolved dependencies. The build makes the installed packages' [license and notice text](/notices/site-dependencies.txt) available with the artifact, including applicable font notices. The bundle also includes development-tool notices for completeness; listing a package there does not claim that all of its code ships to the browser. The site uses system fonts through VitePress’s font-free theme and does not redistribute its default Inter font files.
