# Unpolished

Coordinate bounded agent work and audit instruction changes.

Choose by the task you have now. These are the collection's groups, including external recommendations. They are not a mandatory delivery pipeline.

## [`instruction-maintenance`](/skills/instruction-maintenance)

Audit instruction drift, routing, and skill metadata; propose exact changes for human approval before mutation.

**Choose it when:** Instruction routing, dependencies, metadata, or policy documents appear missing, stale, conflicting, or unsuitable.

## [`subagent-orchestration`](/skills/subagent-orchestration)

Before delegating, bound child-agent work, assign read/write lanes, integrate results, review, validate, and clean temporary lanes.

**Choose it when:** The operator has authorized bounded specialist, independent-review, or parallel work.
