# Diagrams

Choose editable images or interactive HTML for the reader's task.

Choose by the task you have now. These groups describe reader needs, not a mandatory delivery pipeline.

## [`archify`](/skills/archify)

Generate validated interactive HTML diagrams or one-page explainers with Archify, including architecture, workflows, Mermaid input, and image/SVG/WebM exports.

**Choose it when:** You need an explorable standalone HTML diagram for relationships, workflows, states, schemas, or other supported structures.

## [`excalidraw`](/skills/excalidraw)

Generate PNG or SVG diagrams with local Excalidraw rendering. Use for project structure, component relationships, workflows, or revisions to an existing diagram. Retain scene JSON as editable source and deliver images first.

**Choose it when:** You want an editable Excalidraw scene with a PNG or SVG for a project structure, workflow, or component explanation.
