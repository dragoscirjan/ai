# Documentation and communication

Explain technical work and write instructions that readers can follow.

Choose by the task you have now. These groups describe reader needs, not a mandatory delivery pipeline.

## [`document-project`](/skills/document-project)

Maintain task-based developer documentation during implementation; create or refactor VitePress/MkDocs documentation within approved scope.

**Choose it when:** Implementation changes how readers use the project, or existing documentation blocks a real developer task.

## [`asd-ste100-technical`](/skills/asd-ste100-technical)

Technical writing: use ASD-STE100-inspired plain language for software responses and documentation.

**Choose it when:** Technical instructions or explanations need plain language without losing conditions, risks, or precise identifiers.

## [`caveman`](/skills/caveman)

Concise communication that preserves complete technical substance.

**Choose it when:** You explicitly want terse technical fragments and your project policy permits that style.

## [`unslop`](/skills/unslop)

Remove AI-generated prose patterns while preserving meaning.

**Choose it when:** A draft contains generic phrasing, repetitive structure, filler, or claims that do not help the reader act.

## [`writing-for-agents`](/skills/writing-for-agents)

Writing documents for agents. Use when creating or editing skills, or modifying AGENTS.md or CLAUDE.md.

**Choose it when:** The reader is an agent: you are authoring or revising skills, prompts, agent instructions, or their reference documents.

## Try a workflow

- [Keep a developer task usable](/workflows/maintain-task-based-docs) — Implementation changed first use, configuration, behavior, or maintenance instructions.
- [Write guidance for an agent reader](/workflows/write-agent-facing-guidance) — A skill, prompt, or agent-facing document needs clearer triggers and actions.
- [Shorten a technical answer without losing meaning](/workflows/shorten-without-loss) — A useful answer is buried under repetition or generic framing.
