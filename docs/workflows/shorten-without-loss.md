# Shorten a technical answer without losing meaning

A useful answer is buried under repetition or generic framing.

**Finish with:** A concise explanation that retains decisions, commands, risks, and uncertainty.

## Before you start

Use a trusted project and follow its instructions. Confirm the requested scope, installed skills, runtime tools, and any required workspace or approval. No additional instruction requirement is recorded for these selected steps.

## Where to stop

This route retains complete sentences. Caveman is a separate fragment-style alternative, not an extra pass: choose it only when project policy permits, and explicitly disable it before using ASD or Unslop whole-sentence guidance. Prefer one guide when enough; do not trade meaning for brevity.

## Optional branches

- Choose [`document-project`](/skills/document-project) when implementation changes how readers use the project, or existing documentation blocks a real developer task.
- Choose [`caveman`](/skills/caveman) when you explicitly want terse technical fragments and your project policy permits that style.

Optional branches are not prerequisites or permission to launch another phase. You can omit them or stop at the stated result. See [relationship types](/reference/relationships) for the distinction.
