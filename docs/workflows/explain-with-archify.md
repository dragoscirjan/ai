## Before you start

Use a trusted project and follow its instructions. Confirm the requested scope, installed skills, runtime tools, and any required workspace or approval. No additional instruction requirement is recorded for these selected steps.

## Steps

1. **Review source; choose mode.** [`archify`](/skills/archify) provides the guidance for this step.
2. **Approve missing tools.** [`archify`](/skills/archify) owns this approval boundary; continue only when the applicable approval or existing approved setup is established.
3. **Author complete candidate.** [`archify`](/skills/archify) provides the guidance for this step.
4. **Run required finalize gates.** [`archify`](/skills/archify) provides the guidance for this step.
5. **Explain scope; link output.** [`document-project`](/skills/document-project) provides the guidance for this step.

## Where to stop

The setup gate applies only when tools are missing; skip it when reviewed setup already exists. Browser checks are not the same as perceptual review or human user testing.

## Optional branches

- Choose [`asd-ste100-technical`](/skills/asd-ste100-technical) when technical instructions or explanations need plain language without losing conditions, risks, or precise identifiers.

Optional branches are not prerequisites or permission to launch another phase. You can omit them or stop at the stated result. See [relationship types](/reference/relationships) for the distinction.
