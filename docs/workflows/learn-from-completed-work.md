# Turn a completed issue into a small improvement

A bounded work period has enough evidence to examine the process.

**Finish with:** A few actionable improvements, with follow-up authority separated from the retrospective.

Arrows show this suggested sequence, not declared `requires` dependencies. Approval arrows are conditional. Declining a gate stops that branch without authorizing its writes. The numbered steps below are the text equivalent of the diagram.

## Before you start

Use a trusted project and follow its instructions. Confirm the requested scope, installed skills, runtime tools, and any required workspace or approval. No additional instruction requirement is recorded for these selected steps.

## Steps

1. **Bound period + evidence.** [`retro`](/skills/retro) provides the guidance for this step.
2. **Check causes vs impressions.** [`retro`](/skills/retro) provides the guidance for this step.
3. **Check causal evidence.** [`retro`](/skills/retro) provides the guidance for this step.
4. **Propose small follow-ups.** [`retro`](/skills/retro) provides the guidance for this step.

## Where to stop

Stop at proposals; tool changes, instruction edits, cleanup, and publication need their own approval. Use the optional wait-what branch only when the retrospective's explanation needs more context or clearer terms.

## Optional branches

- Choose [`instruction-maintenance`](/skills/instruction-maintenance) when instruction routing, dependencies, metadata, or policy documents appear missing, stale, conflicting, or unsuitable.
- Choose [`document-project`](/skills/document-project) when implementation changes how readers use the project, or existing documentation blocks a real developer task.
- Choose [`wait-what`](/skills/wait-what) when the last answer is hard to understand or omits context needed to follow the current proposal.

Optional branches are not prerequisites or permission to launch another phase. You can omit them or stop at the stated result. See [relationship types](/reference/relationships) for the distinction.
