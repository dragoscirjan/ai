# Keep a developer task usable

This is a focused procedure. For its place in a larger workflow, see [Document a project](/workflows/document-a-project).

**Finish with:** A checked procedure with prerequisites, actions, expected results, and recovery guidance.

## Before you start

Use a trusted project and follow its instructions. Confirm the requested scope, installed skills, runtime tools, and any required workspace or approval. No additional instruction requirement is recorded for these selected steps.

## Steps

1. **Choose the reader's task.** [`document-project`](/skills/document-project) provides the guidance for this step.
2. **Update the procedure.** [`document-project`](/skills/document-project) provides the guidance for this step.
3. **Preserve precise meaning.** [`asd-ste100-technical`](/skills/asd-ste100-technical) provides the guidance for this step.
4. **Remove generic framing.** [`unslop`](/skills/unslop) provides the guidance for this step.
5. **Walk through; check links.** [`document-project`](/skills/document-project) provides the guidance for this step.

## Where to stop

Use a diagram only when it answers a relationship question. A new site or toolchain is a separate approved baseline, not a routine documentation side effect.
