# Sources and local choices

## Sources reviewed

- Superpowers' [brainstorming](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/skills/brainstorming/SKILL.md) reads project context before asking questions, establishes the user's reasons and success conditions, and distinguishes user decisions from agent proposals.
- Matt Pocock's [wayfinder](https://github.com/mattpocock/skills/blob/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d/skills/engineering/wayfinder/SKILL.md) separates resolving decisions from executing work. Its full decision-ticket system is outside this brief's scope.

## Local choices

Ask who has the problem, what happens today, and what would make the effort succeed or fail. Use the existing required interview to settle only what remains open. Record an outcome brief without turning it into a technical design.

Keep `require: ["grilling"]`. Do not import another interview skill, automatic tracker tickets, fixed paths, prototype exceptions, design-review agents, or an automatic handoff to implementation planning. The source links are references, not additional skill dependencies.
