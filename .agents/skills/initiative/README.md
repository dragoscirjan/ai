## Local choices

Accept prior research, a direct user request, or both. Record the starting point and context references. Research findings provide evidence; their recommendations are not user decisions until accepted.

Reuse available context before asking questions. Investigate missing facts and use the existing required interview to settle initiative-level choices. Confirm the problem, outcome, scope, constraints, and success conditions before writing. Do not draft around unresolved decisions or invent missing evidence. After clarification, resolve where and how to save an agreement record. Ask the user if the destination or format is not already explicit. Save the chosen issue or document, verify its content, and return its path or URL. Report an unsaved or unverified state honestly when access or permissions block completion. Keep technical design and implementation planning downstream.

Keep `requires: ["grilling"]`. Do not import another interview skill, automatic tracker tickets, fixed paths, prototype exceptions, design-review agents, or an automatic handoff to implementation planning. The source links are references, not additional skill dependencies.
