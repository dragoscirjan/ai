# Sources and local choices

## Sources reviewed

- Matt Pocock's [research](https://github.com/mattpocock/skills/blob/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d/skills/engineering/research/SKILL.md) follows claims to primary sources and cites them in one findings document.
- Cursor pstack's [figure-it-out](https://github.com/cursor/plugins/blob/2eaf46574b25cdf7ef8c849837099b866b7438ce/pstack/skills/figure-it-out/SKILL.md) tests claims against actual results and treats inconclusive evidence as inconclusive.
- Vercel's [find-skills](https://github.com/vercel-labs/skills/blob/e781cb4d07433dfe1d19e924ed45cc61738c55ec/skills/find-skills/SKILL.md) searches for existing skills and checks candidates before recommending them. This repository offers discovery tooling, not a general research workflow.

## Local choices

Cite claims that affect the answer, retain contrary evidence, and state what would resolve uncertainty. Keep the user's decision separate from the researcher's recommendation.

Do not copy mandatory background agents, fixed note locations, installation commands, or popularity thresholds as evidence of correctness. The user chooses the destination when project instructions do not provide it.

The four-repository audit also examined Superpowers' brainstorming and planning guidance. Those methods inform the initiative, specification, and task skills rather than adding a requirement here. The source links are references, not skill dependencies.
